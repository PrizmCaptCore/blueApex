# BlueApex

Windows 11용 바탕화면 아이콘 정리 프로그램. Stardock Fences처럼 바탕화면에 "구역"을 두고,
그 안에 들어온 아이콘을 자동으로 격자 정렬한다. 탐색기에 DLL을 주입하지 않고 외부 프로세스에서
공개 셸 API(IFolderView)와 바탕화면 창 계층만 사용한다.

## 구성

- `src/BlueApex/` — 앱 (C# / .NET 9 / WPF, 트레이 상주)
  - `Desktop/DesktopHost.cs` — 탐색기 바탕화면 창 계층을 찾고, 구역 창을 아이콘 아래에 끼워 넣는다.
  - `Desktop/DesktopIconView.cs` — 아이콘 목록·위치 읽기, 위치 지정(IFolderView).
  - `Zones/ZoneManager.cs` — 구역 소유, 멤버 자동 정렬, 아이콘 드래그 감지(폴링), 저장.
  - `Zones/ZoneSurface.cs` — 구역 배경 창. 이 빌드에서 합성되는 창 종류에 대한 제약은 주석 참고.
- `tools/DesktopProbe/` — 읽기 전용 진단 도구. 창 구조와 아이콘 목록을 출력한다.
  Windows 업데이트 후 뭔가 깨지면 먼저 실행해 본다.

## 실행

```sh
dotnet run --project src/BlueApex
```

앱은 트레이에 상주한다. 안드로이드 홈 화면/앱 서랍과 같은 두 층 구조다.

- **바탕화면(홈)**: 꺼내 둔(고정) 아이콘만 보인다. 나머지 파일에는 **숨김 속성**을 걸어 탐색기가 스스로 안 보여 주게 한다.
  아이콘 좌표는 건드리지 않으므로 꺼내면 원래 자리로 돌아온다. 처음 실행하면 휴지통만 남고 전부 서랍으로 들어간다.
  - 공용 바탕화면(`C:\Users\Public\Desktop`, 설치 프로그램이 만든 바로가기)은 권한이 없으면 숨길 수 없다.
    트레이 "공용 바탕화면 권한 설정"으로 한 번 관리자 권한을 받아 `icacls`로 속성 변경 권한을 상속 부여한다.
  - 휴지통 같은 셸 항목은 파일이 아니라 항상 바탕화면에 남는다.
  - 탐색기 옵션 "숨김 파일 표시"가 켜져 있으면 서랍에 넣은 아이콘이 흐리게 보인다(시작 때 알림).
- **서랍**: 바탕화면 아래 가운데의 둥근 버튼(점 9개) 클릭, `Ctrl+Shift+Space`(layout.json의 `Hotkey`로 변경),
  트레이 아이콘 클릭, 트레이 메뉴 "서랍 열기"로 연다. 버튼은 끌어서 옮길 수 있고 위치가 저장된다(`ButtonX`/`ButtonY`).
  구역이 카드로 나열되고 각 카드에 멤버 아이콘이 보인다. 규칙에 걸리지 않은 아이콘은 모두 **기본 구역**(처음엔 "기본")에 모인다.
  기본 구역은 지울 수 없고, 다른 구역 제목 우클릭 → "기본 구역으로 지정"으로 바꿀 수 있다.
  - 타이핑하면 검색, Enter는 첫 결과 실행, Esc·빈 곳 클릭·다른 창 활성화로 닫힘.
  - 아이콘 클릭 → 실행. 우클릭 → 바탕화면에 꺼내기/서랍에 넣기, 구역으로 이동, 파일 위치 열기, 삭제(휴지통으로).
  - 아이콘을 다른 카드로 끌어다 놓으면 구역 이동. 카드 제목 우클릭 → 이름 바꾸기, 자동 분류 규칙, 구역 삭제. "+ 새 구역" 버튼.
  - 전체 화면 앱(게임)이 앞에 있으면 단축키를 무시한다.
- **새 아이콘**이 바탕화면에 생기면 자동 분류 규칙으로 구역을 정하고 바로 서랍에 넣는다(트레이 알림).
- **안전장치**: 앱이 숨긴 파일 목록을 layout.json(`HiddenByApp`)에 저장하고, 정상 종료 시 전부 숨김을 푼다.
  트레이 "숨긴 아이콘 모두 보이기"로 언제든 풀 수 있고, 비정상 종료 뒤엔 다시 실행하면 목록을 이어받는다.
  아이콘 위치 백업/복원도 남아 있다(시작할 때마다 자동 백업, 최근 10개 보관).
- 자동 분류 규칙: 한 줄에 하나씩 파일 이름 와일드카드(`*.url`, `Steam*`, `folder:*`, `file:*.pdf`).
  트레이의 "규칙대로 지금 정리"는 어느 구역에도 없는 아이콘에 규칙을 적용한다.
- 레이아웃: `%AppData%BlueApexayout.json`. 판단 기록: `%AppData%BlueApexog.txt`.
- 시작 시 자동 실행: 트레이 메뉴(HKCU Run 등록).

`Zones/` 아래의 바탕화면 구역 창·드래그·접기 코드는 이전 방식(바탕화면에 구역을 그리는 Fences 방식)이며 현재는 쓰지 않는다.

## 검증된 환경

Windows 11 빌드 26300 (26H2), 3840x2160 150%, Wallpaper Engine 사용 중.
