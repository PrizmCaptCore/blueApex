# BlueApex

Windows 11용 바탕화면 아이콘 정리 프로그램. Stardock Fences처럼 바탕화면에 "구역"을 두고,
그 안에 들어온 아이콘을 자동으로 격자 정렬한다. 탐색기에 DLL을 주입하지 않고 외부 프로세스에서
공개 셸 API(IFolderView)와 바탕화면 창 계층만 사용한다.

## 구성

- `src/BlueApex/` — 앱 (C# / .NET 9 / WPF, 트레이 상주)
  - `Desktop/DesktopHost.cs` — 탐색기 바탕화면 창 계층을 찾고, 구역 창을 아이콘 아래에 끼워 넣는다.
  - `Desktop/DesktopIconView.cs` — 아이콘 목록·위치 읽기, 위치 지정(IFolderView).
  - `Zones/ZoneManager.cs` — 구역 소유, 멤버 자동 정렬, 아이콘 드래그 감지(폴링), 저장.
  - `Zones/ZoneSurface.cs` — 구역 배경 창. 이 빌드에서 합성되는 창 종류에 대한 제약은 주석 참고.
- `tools/DesktopProbe/` — 읽기 전용 진단 도구. 창 구조와 아이콘 목록을 출력한다.
  Windows 업데이트 후 뭔가 깨지면 먼저 실행해 본다.

## 실행

```sh
dotnet run --project src/BlueApex
```

- 구역은 제목 표시줄을 끌어 옮기고, 오른쪽 아래 모서리의 빗금 손잡이를 끌어 크기를 바꾼다. 멤버 아이콘이 따라온다.
  바탕화면 위의 마우스 입력은 탐색기가 받으므로, 저수준 마우스 훅(`ZoneMouseInteraction.cs`)으로 가로챈다.
- 빈 바탕화면에서 오른쪽 버튼으로 끌어 사각형을 그리면 그 자리에 새 구역이 생기고 이름을 묻는다(안에 있던 아이콘은 멤버가 된다).
  끌지 않고 그냥 우클릭하면 평소처럼 탐색기 메뉴가 뜬다.
- 제목 표시줄 더블클릭 → 접기/펼치기(멤버 아이콘은 화면 위 밖에 치워 둔다). 빈 바탕화면 더블클릭 → 아이콘·구역 전부 숨기기/보이기.
- 제목 표시줄 우클릭 → 이름 바꾸기 / 새 구역 / 구역 삭제. 삭제해도 아이콘은 그 자리에 남는다.
- 자동 분류 규칙: 구역 제목 우클릭 → "자동 분류 규칙...". 한 줄에 하나씩 파일 이름 와일드카드(`*.url`, `Steam*`, `folder:*`, `file:*.pdf`).
  새로 생기는 아이콘은 규칙에 맞는 첫 구역으로 들어가고, 트레이의 "규칙대로 지금 정리"는 어느 구역에도 없는 아이콘에 규칙을 적용한다.
- 레이아웃: `%AppData%\BlueApex\layout.json` (트레이 메뉴 "레이아웃 파일 열기").
  파일을 고치면 바로 반영된다. 좌표는 물리 픽셀, 바탕화면 아이콘 영역 기준.
- 구역 안으로 아이콘을 끌어다 놓으면 멤버가 되어 격자에 정렬되고, 밖으로 끌어내면 빠진다.
  여러 개를 한 번에 끌어다 놓아도 된다(놓은 순서대로 칸에 들어간다).
- 사용자가 옮긴 것과 탐색기가 옮긴 것은 선택 상태로 구분한다: 드래그한 아이콘은 놓은 뒤에도 선택되어 있다.
  선택되지 않은 채 움직인 멤버는 제자리로 되돌린다.
- 트레이 메뉴: 아이콘 배치 백업/복원(시작할 때마다 자동 백업, 최근 10개 보관, `%AppData%BlueApexackups`),
  시작 시 자동 실행(HKCU Run 등록).
- 판단 기록은 `%AppData%\BlueApex\log.txt`에 남는다. 아이콘이 이상하게 움직이면 여기를 본다.
- 실행 중에는 탐색기의 "아이콘을 그리드에 맞춤"/"자동 정렬"을 끈다. 종료 시 원래대로 되돌린다.

## 검증된 환경

Windows 11 빌드 26300 (26H2), 3840x2160 150%, Wallpaper Engine 사용 중.
