# BlueApex 사용법과 동작 방식

앱은 트레이에 상주한다. 안드로이드 홈 화면/앱 서랍과 같은 두 층 구조다.

## 바탕화면(홈)

- 꺼내 둔(고정) 아이콘만 보인다. 나머지 파일에는 **숨김 속성**을 걸어 탐색기가 스스로 안 보여 주게 한다.
  아이콘 좌표는 건드리지 않으므로 꺼내면 원래 자리로 돌아온다. 처음 실행하면 휴지통만 남고 전부 서랍으로 들어간다.
- 공용 바탕화면(`C:\Users\Public\Desktop`, 설치 프로그램이 만든 바로가기)은 권한이 없으면 숨길 수 없다.
  트레이 "공용 바탕화면 권한 설정"으로 한 번 관리자 권한을 받아 `icacls`로 속성 변경 권한을 상속 부여한다.
- 휴지통 같은 셸 항목은 파일이 아니라 항상 바탕화면에 남는다.
- 탐색기 옵션 "숨김 파일 표시"가 켜져 있으면 서랍에 넣은 아이콘이 흐리게 보인다(시작 때 알림).
- **새 아이콘**이 바탕화면에 생기면 자동 분류 규칙으로 구역을 정하고 바로 서랍에 넣는다(트레이 알림).

## 서랍

- 여는 법: 바탕화면 아래 가운데의 둥근 버튼(점 9개) 클릭, `Ctrl+Shift+Space`(layout.json의 `Hotkey`로 변경),
  트레이 아이콘 클릭, 트레이 메뉴 "서랍 열기". 버튼은 끌어서 옮길 수 있고 위치가 저장된다.
- 구역이 카드로 나열되고 각 카드에 멤버 아이콘이 보인다. 규칙에 걸리지 않은 아이콘은 모두 **기본 구역**(처음엔 "기본")에 모인다.
  기본 구역은 지울 수 없고, 다른 구역 제목 우클릭 → "기본 구역으로 지정"으로 바꿀 수 있다.
- 타이핑하면 검색, Enter는 첫 결과 실행, Esc·빈 곳 클릭·다른 창 활성화로 닫힘.
- 빈 곳에서 끌어 사각형으로 여러 개 선택(Ctrl을 누르면 기존 선택에 추가). Ctrl+클릭은 하나씩 토글, Shift+클릭은 범위,
  Ctrl+A는 보이는 전부. 선택한 채로 끌거나 우클릭하면 전부에 적용된다.
- 아이콘 클릭 → 실행. 우클릭 → 바탕화면에 꺼내기/서랍에 넣기, 구역으로 이동, 파일 위치 열기, 삭제(휴지통으로).
- 아이콘을 다른 카드로 끌어다 놓으면 구역 이동. 끄는 동안 아래에 나타나는 "바탕화면에 꺼내기"/"휴지통으로"에 놓아도 된다.
  카드의 빈 곳이나 제목 우클릭 → 새 폴더 만들기(바탕화면에 만들고 이 구역에 넣음), 이름 바꾸기, 자동 분류 규칙, 폴더 포털로 바꾸기, 구역 삭제.
  "+ 새 구역", "+ 폴더 포털" 버튼.
- **폴더 포털**: 폴더 하나의 내용을 그대로 보여 주는 구역(예: 사진 폴더). 폴더 안의 파일·하위 폴더가 최신순으로 기본 4줄(16개)까지 보이고("더 보기"로 추가, 최대 1000개;
  줄 수는 포털 카드 우클릭 → "한 번에 보일 줄 수"로 바꾸며 layout.json `PortalRows`에 저장),
  사진·동영상은 파일 아이콘이 먼저 뜬 뒤 백그라운드에서 만든 썸네일로 바뀐다(동시에 2개씩만 디코딩). 클릭 → 열기, 우클릭 → 열기 / 파일 위치 열기 / 삭제, 카드 우클릭 → 폴더 열기 / 그 안에 새 폴더 / 포털 폴더 바꾸기 / 포털 해제.
  포털의 파일은 바탕화면 항목이 아니므로 꺼내기·구역 이동·규칙 대상이 아니다. 서랍을 열 때마다 폴더를 다시 읽는다.
- 전체 화면 앱(게임)이 앞에 있으면 단축키를 무시한다.

## 설치된 앱

서랍 끝의 **"모든 앱"** 카드에 설치된 프로그램과 스토어 앱이 전부 나온다(시작 메뉴의 "모든 앱"과 같은 목록, 셸의 `shell:AppsFolder`).
포털처럼 줄 수만큼 보이고 "더 보기"로 늘리며, **검색은 아직 안 펼친 항목까지 찾는다.** 클릭 → 실행.
목록은 시작 때와 10분마다 백그라운드에서 다시 읽는다. 트레이 "서랍에 설치된 앱 전부 표시"로 카드를 끄고 켠다.
정렬은 카드 우클릭에서 고른다: **A→Z 먼저, 그다음 가나다**(기본) 또는 **가나다 먼저**(layout.json `AppSort`).
구역 카드도 우클릭 → "이름순으로 정렬 (한 번)"으로 같은 순서로 멤버를 정렬할 수 있다(이후 끌어 놓은 순서는 그대로 유지).

## 게임 라이브러리 (Steam · Epic Games · GOG)

"모든 앱" 다음의 **"게임"** 카드에 런처들이 아는 게임이 모인다. 전부 PC에 이미 있는 파일을 읽을 뿐, 비밀번호는 다루지 않는다.

| 런처 | 설치된 게임 | 설치 안 한 보유 게임 |
| --- | --- | --- |
| Steam | 라이브러리 폴더의 `appmanifest_*.acf` | 카드 우클릭 → **"Steam 로그인"** 창에서 Steam에 로그인(아래) |
| Epic Games | 런처의 `Manifests\*.item` | 런처에 **로그인돼 있으면 자동**(런처가 둔 카탈로그 캐시를 읽음) |
| GOG | 레지스트리 (`GOG.com\Games`) | 안 읽음(GOG Galaxy 로그인 뒤에만 있는 목록) |

- 설치된 게임은 클릭 → 실행(Steam은 `steam://rungameid/…`, Epic은 `com.epicgames.launcher://…`, GOG는 exe 직접).
- 설치 안 한 게임은 **흐리게** 보이고, 클릭하면 런처의 설치 화면이 열린다. 카드 우클릭 "미설치 게임도 보기"로 숨길 수 있다.
- 배치 선택: **런처별**(기본: 런처 묶음을 열면 그 안에 글자별 묶음이 또 있다) / 전체 / 글자별. 타일은 앱처럼 구역에 끌어 넣고, "바탕화면에 꺼내기"에 떨어뜨리면 `.url` 바로가기가 생긴다.
- 그림은 Steam 캐시 폴더나 각 CDN에서 가져와 `%AppData%\BlueApex\cache\games`에 한 번만 저장한다.
- Steam 로그인: Playnite와 같은 방식이다. 앱 안의 작은 브라우저 창(Edge WebView2)에 Steam의 진짜 로그인 페이지가 뜨고, 거기서 로그인하면
  그 세션으로 Steam이 주는 임시 토큰을 받아 공식 API로 보유 게임을 읽는다. 비밀번호는 앱이 보지 않는다.
  세션은 `%AppData%\BlueApex\browser`에 남아 하루에 한 번 조용히 목록을 갱신하고, Steam이 다시 로그인을 요구하면 트레이 알림으로 알려 준다.
  프로필 > 개인정보 설정의 **"게임 세부 정보"가 비공개**면 본인 계정이라도 목록을 주지 않는다. "Steam 로그아웃"으로 세션과 목록을 지운다.
- 목록은 시작 때와 10분마다 다시 읽고, 카드 우클릭 "라이브러리 다시 읽기"로 바로 읽는다. 트레이 "서랍에 게임 라이브러리 표시"로 카드를 끄고 켠다.

## 카드 접기

카드 제목을 클릭하면 그 카드만 제목 줄로 접히고, 다시 클릭하면 펼쳐진다(우클릭 메뉴의 "접기/펼치기"도 같다).
구역·모든 앱·게임 카드 모두 되고, 상태는 저장되어 다음에 서랍을 열어도 그대로다. 접힌 카드에도 아이콘을 끌어다 놓을 수 있다.

## 구역 안의 작은 서랍 (묶음)

구역 카드 제목 오른쪽의 선택 상자에서 배치를 고른다(구역마다 저장, `SortMode`):

- **수동** — 끌어 놓은 순서대로 한 판에 펼침(기본).
- **이름** — A, B, …, 0-9, ㄱ, ㄴ… 글자별 묶음.
- **날짜** — 오늘 / 어제 / 이번 주 / 이번 달 / 올해 / 이전 / 날짜 없음(앱·휴지통) 묶음, 각 묶음은 최신순.
- **종류** — 앱 / 바로가기 / 폴더 / 이미지 / 문서 / 파일 / 시스템 묶음.

묶음은 접힌 줄로 보이고 누르면 열린다(열림 상태는 서랍을 닫아도 그 세션 동안 유지). 열린 묶음은 포털처럼 줄 수 설정만큼 보이고 "더 보기"로 늘린다.
검색하면 맞는 항목이 있는 묶음이 자동으로 열리고, 검색어를 지우면 원래 상태로 돌아간다.
"모든 앱" 카드도 선택 상자에서 **전체 / 글자별**을 고를 수 있다(`AppSections`).

앱은 **구역에 넣을 수 있다**: 타일을(또는 범위 선택한 여러 개를) 구역 카드로 끌거나 우클릭 → "구역에 추가". 구역에는 앱 id만 기록되고
바탕화면에는 아무 파일도 생기지 않는다. 구역 안의 앱 타일 우클릭 → 구역으로 이동 / 구역에서 빼기. "휴지통으로"에 놓으면 구역에서 빠질 뿐이다.
**"바탕화면에 바로가기 만들기"**(또는 "바탕화면에 꺼내기"에 놓기)를 하면 시작 메뉴에서 끌어다 놓은 것과 같은 바로가기 파일이 바탕화면에
생겨 보이고, 구역에서는 그 바로가기가 앱의 자리를 이어받는다.

## 자동 분류 규칙

한 줄에 하나씩 파일 이름 와일드카드(`*.url`, `Steam*`, `folder:*`, `file:*.pdf`). 구역 제목 우클릭 → "자동 분류 규칙...".
새로 생기는 아이콘은 규칙에 맞는 첫 구역으로 들어간다. 트레이의 "규칙대로 지금 정리"는 기본 구역의 아이콘에 규칙을 적용한다.

## 위젯

트레이 메뉴 "위젯 추가" → 시계 / 메모 / (설치한 플러그인). 바탕화면 층(아이콘 아래)에 그려지고 끌어서 옮긴다.
우클릭 → 위젯별 메뉴 / 위젯 삭제. 위치·설정은 layout.json `Widgets`에 저장. 플러그인 만들기는 [widget-sdk.md](widget-sdk.md).

## 안전장치

- 앱이 숨긴 파일 목록을 layout.json(`HiddenByApp`)에 저장하고, 정상 종료 시 전부 숨김을 푼다.
  트레이 "숨긴 아이콘 모두 보이기"로 언제든 풀 수 있고, 비정상 종료 뒤엔 다시 실행하면 목록을 이어받는다.
- 아이콘 위치 백업/복원: 시작할 때마다 자동 백업, 최근 10개 보관, 트레이 "아이콘 배치 백업/복원".
- 처리되지 않은 오류는 로그에 남기고 앱은 계속 실행된다. 프로세스가 내려가는 경우에도 숨김을 풀려고 시도한다.
- `BlueApex.exe --exit`는 실행 중인 인스턴스를 정상 종료시킨다(스크립트·설치 프로그램용).

## 파일

- 설정: `%AppData%\BlueApex\layout.json` (트레이 "레이아웃 파일 열기"). 깨져 있으면 `layout.broken-날짜.json`으로 옮기고 기본값으로 시작한다.
- 로그: `%AppData%\BlueApex\log.txt`
- 플러그인: `%AppData%\BlueApex\widgets\<이름>\`
- 시작 시 자동 실행: 트레이 메뉴(HKCU Run 등록)

## 코드 구성

- `src/BlueApex/` — 앱 (C# / .NET 9 / WPF)
  - `Drawer/` — 서랍 창, 홈 화면 모델(숨기기/꺼내기), 바탕화면 버튼, 단축키
  - `Desktop/` — 탐색기 바탕화면 창 계층, 아이콘 뷰(IFolderView), 숨김 속성·권한, 바탕화면 층 창과 마우스 훅
  - `Widgets/` — 위젯 호스트, 내장 위젯, 플러그인 로더
  - `Zones/` — 구역 모델·규칙·저장. 이 아래의 바탕화면 구역 창·드래그·접기 코드는 이전 방식(Fences식)이며 현재는 쓰지 않는다.
- `src/BlueApex.Sdk/` — 위젯 플러그인 계약
- `samples/` — 플러그인 예제(날씨, 미디어)
- `tools/DesktopProbe/` — 읽기 전용 진단 도구. 창 구조와 아이콘 목록을 출력한다. Windows 업데이트 후 뭔가 깨지면 먼저 실행해 본다.

## 검증된 환경

Windows 11 빌드 26300 (26H2), 3840x2160 150%, Wallpaper Engine 사용 중. 바탕화면 버튼·위젯은 24H2 이후의
바탕화면 창 구조에 맞춰져 있고, 그 이전 버전에서는 단축키·트레이로만 서랍을 연다.
